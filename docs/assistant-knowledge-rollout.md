# 小水滴资料库：部署和验收

## 部署前

1. 在当前网站使用的 Supabase 项目依次运行 `supabase/migrations/20261021_assistant_knowledge.sql` 和 `supabase/migrations/20261029065330_rag_hybrid_search.sql`。第一项创建资料、片段、权限策略与私有文件桶；第二项把已核对的 6 条公共摘要写入资料库，并将检索改为权限过滤后的关键词与语义排序融合。两项均不修改监测数据。
2. 确认 Vercel 服务端已配置 `SUPABASE_SERVICE_ROLE_KEY`（或项目使用的 `COZE_SUPABASE_SERVICE_ROLE_KEY`）。密钥只在服务端使用，切勿添加 `NEXT_PUBLIC_` 前缀。现有对话的 `WATER_AI_API_KEY` 继续用于聊天。
3. 要启用语义检索，在 Vercel 服务端设置 `WATER_AI_EMBEDDING_MODEL=text-embedding-v4`；若当前聊天模型的兼容 API 不支持向量接口，再设置专用的 `WATER_AI_EMBEDDING_API_KEY` 和 `WATER_AI_EMBEDDING_BASE_URL`。向量输出须为 1024 维。先在预览分支配置并测试接口，再扩展至 Production。未配置或接口失败时资料仍可发布，但会显示“关键词检索”；配置完成后管理员打开已发布资料，点击“更新语义索引”。每篇资料均须完成索引后才显示“混合检索”。

## 使用流程

- 企业在“**小水滴资料库**”上传 PDF、DOCX、TXT、MD，或粘贴文字。可填写标题、版本、来源链接及生效日期。文件最多 4MB、正文最多 5 万字，扫描 PDF 不进行 OCR。提交后只能预览，尚不会进入聊天检索。
- 所属园区管理员在资料库页面打开片段预览，核对原文和适用范围，选择“审核并发布”或“退回资料”。管理员也可提交园区或公共资料；过时资料可归档。版本由资料标题和版本字段表示，发布新版本后应归档旧版本。
- 企业在对话和资料清单中可查看已发布的公共、所属园区与本企业资料，也能查看本人待审核资料；管理员可查看公共及所属园区所有企业资料。资料检索使用登录用户的 Supabase JWT 访问受行级权限限制的检索函数，不能由模型提交园区或用户 ID 改变查询范围。
- 搜索同时考虑关键词和语义向量，并对两个候选列表做排序融合；同一文档最多返回两个片段。片段按相关性排序，回答引用 `[资料1]` 等标签。下方资料卡可查看原文、章节/页码、版本、来源和原件。监测记录仍由独立的授权数据工具查询，不能用上传文档替代实时监测证据。

## 验收建议

1. 企业 A 提交排口说明，管理员预览并发布。企业 A 问该排口操作说明，应能看到引用片段；发布前不可作为聊天证据。
2. 企业 B 问企业 A 的说明：不应返回企业 A 资料；同园区管理员可查询企业 A 和 B，跨园区管理员不可访问。
3. 上传有明确“第 2 页”文字的 PDF，聊天引用应指向第 2 页；上传仅含扫描图像的 PDF 应提示提取不到文字。
4. 问监测波动与采样质控的综合问题：要看到实际监测工具证据与资料片段两类依据；无监测数据不能宣称正常。
5. 归档旧版本或设置失效日期后再提问：旧资料不应参与聊天检索。

2026-10-29 已在 `w-cdc` Supabase 项目应用两项迁移。新库目前有 6 篇已发布公共摘要和 6 个片段；当前向量片段数为 0，仍为关键词检索。正式站企业账号可在小水滴回答中看到这些数据库资料的章节与来源链接。向量接口与管理员更新索引需要在预览环境验证后，再将模型配置用于正式环境。
