# 小水滴资料库：部署和验收

## 部署前

1. 在当前网站使用的 Supabase 项目依次运行 `supabase/migrations/20261021_assistant_knowledge.sql`、`supabase/migrations/20261029065330_rag_hybrid_search.sql` 和 `supabase/migrations/20261029135630_global_knowledge_scope.sql`。前两项创建资料库及混合检索，第三项将资料权限调整为管理员全量、企业公共加本人。三项均不修改监测数据。
2. 按需运行 `scripts/seed-rag-standards-2026.sql`，补充 HJ 1209、HJ 819、HJ 91.1、HJ 355、HJ 356 的 5 条官方题录摘要；脚本可重复执行，不会改动用户上传资料或监测数据。它们是带来源链接的摘要，不是标准全文。
3. 确认 Vercel 服务端已配置 `SUPABASE_SERVICE_ROLE_KEY`（或项目使用的 `COZE_SUPABASE_SERVICE_ROLE_KEY`）。密钥只在服务端使用，切勿添加 `NEXT_PUBLIC_` 前缀。现有对话的 `WATER_AI_API_KEY` 继续用于聊天。
4. 要启用语义检索，在 Vercel 服务端设置 `WATER_AI_EMBEDDING_MODEL=text-embedding-v4`；若当前聊天模型的兼容 API 不支持向量接口，再设置专用的 `WATER_AI_EMBEDDING_API_KEY` 和 `WATER_AI_EMBEDDING_BASE_URL`。向量输出须为 1024 维。先在预览分支配置并测试接口，再扩展至 Production。未配置或接口失败时资料仍可发布，但会显示“关键词检索”；配置完成后管理员点击“补齐语义索引”，页面逐份更新并显示成功数与错误。每篇资料均须完成索引后才显示“混合检索”。

## 使用流程

- 企业在“**小水滴资料库**”上传 PDF、DOCX、TXT、MD，或粘贴文字。可填写标题、版本、来源链接及生效日期。文件最多 4MB、正文最多 5 万字，扫描 PDF 不进行 OCR。提交后只能预览，尚不会进入聊天检索。
- 管理员在资料库页面查看全部企业的片段预览，核对原文后选择“审核并发布”或“退回资料”。管理员上传的资料固定为公共资料，核对并发布后所有企业可用；过时资料可归档。版本由资料标题和版本字段表示，发布新版本后应归档旧版本。
- 企业在对话和资料清单中可查看已发布的公共资料及本企业资料，也能预览本人待审核资料；管理员可查看全部企业资料（包括待审核），但只有已发布且在有效期内的资料可用于 RAG。原有的园区资料仅保留为管理员可读的历史记录，不再新增。资料检索使用登录用户的 Supabase JWT 访问受行级权限限制的检索函数，不能由模型提交园区或用户 ID 改变查询范围。监测数据的园区与企业授权规则不受资料库权限调整影响。
- 资料页顶部检索框和小水滴对话共用权限内的关键词／向量召回；同一文档最多返回两个片段。资料页显示片段、章节、版本和来源；对话回答引用 `[资料1]` 等标签。监测记录仍由独立的授权数据工具查询，不能用上传文档替代实时监测证据。

## 验收建议

1. 企业 A 提交排口说明，管理员预览并发布。企业 A 问该排口操作说明，应能看到引用片段；发布前不可作为聊天证据。
2. 企业 B 问企业 A 的说明：不应返回企业 A 资料；管理员可查询全部企业已发布资料，未发布资料只能预览。
3. 上传有明确“第 2 页”文字的 PDF，聊天引用应指向第 2 页；上传仅含扫描图像的 PDF 应提示提取不到文字。
4. 问监测波动与采样质控的综合问题：要看到实际监测工具证据与资料片段两类依据；无监测数据不能宣称正常。
5. 归档旧版本或设置失效日期后再提问：旧资料不应参与聊天检索。
