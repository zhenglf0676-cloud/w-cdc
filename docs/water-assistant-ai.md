# 小水滴 AI 接入（第一阶段）

在部署平台的服务端环境变量中配置，并重新部署：

```
WATER_AI_API_KEY=在部署平台填写新密钥
WATER_AI_BASE_URL=https://maas.qianwenaiapi.com/compatible-mode/v1
WATER_AI_MODEL=qwen3.8-omni-flash
```

密钥不能使用 NEXT_PUBLIC_ 前缀，不能提交到仓库。此前在聊天中公开的密钥应撤销。

点击小水滴，在工作台的对话区输入“分析近7天的水质异常”，随后追问“与前7天相比呢”。右侧快捷操作可生成 Word 报告、开启语音提示或查看污染扩散演示；手机端快捷操作显示在对话区上方。模型通过 analyze_water 工具查询并计算，再解释结果。证据面板展示实际查询日期、企业、按监测点/指标/单位分组的统计、每日均值及最多10条超阈值样本的记录ID。

企业账号可把 `.xlsx`/`.xls` 文件拖入对话区，或点击输入框旁的附件按钮。文件沿用企业监测页的 Excel 表头规则：第一张表至少有“排污口”“时间”，指标列可用 COD、NH3-N、TP、TN、pH、重金属；排污口及指标必须已审批。小水滴先调用现有导入接口的预检模式，展示可录入条数、前5条和错误；仅在全部校验通过且用户点击“确认录入”后，以严格模式写入 monitoring_data。成功后当前企业监测页会重新获取实时值、历史和图表。当前版本按固定表头解析，不识别任意格式文档；管理员暂不支持代录。

企业权限从服务器验证的用户身份确定，仅查询本人企业。管理员限定所属园区。企业名称只能缩小已授权范围，不能扩大权限。模型无法提交SQL、用户ID或园区参数。日期为北京时间，最多31天且不晚于今天。一次请求最多4轮模型调用，每轮最多4个工具，每个工具最多10000条监测记录，返回数据过大时拒绝而不返回残缺统计。

目前聊天记录仅在当前页面的组件内存中，收起工作台再打开可继续对话；刷新页面或切换账号会清空，切换账号时取消未完成请求。错误时保留问题可重试。未配置密钥时保留原报告、预警和演示功能。

本阶段不是完整参赛版本：尚未加入流式响应、联动趋势图、RAG、报告识别、分布式用户限流。正式开放前应在部署网关限制调用频率与预算。现有阈值口径是记录保存的上限，不适用于pH双侧区间，也不等同法定超标；不推断连续异常持续时长。

验证：类型检查与自动测试不使用真实密钥。上线前配置新密钥，并使用两个企业账号及不同园区管理员验证查询范围、工具调用兼容性与费用。此次未调用真实模型或生产数据库。
