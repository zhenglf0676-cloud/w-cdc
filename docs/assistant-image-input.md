# 小水滴图片提问（首版）

企业和管理员均可在对话框点击图片按钮、拖入图片或粘贴截图。单次一张 PNG、JPG 或 WEBP，不超过 2MB。图片只随本次请求发送到现有阿里云百炼兼容接口，不存入资料库或监测数据表；Excel 录入仍需单独预检并确认。

小水滴先输出图片的可见事实和不确定部分，再根据用户的问题调用现有、受账号权限限制的监测与资料检索工具。展开“查看图片识别内容”可核对视觉模型读到了什么。图片上写着的数值只属于图片观察，不能冒充数据库记录；涉及超审批上限、历史变化或标准适用性时，应分别核对数据库和资料依据。图片中的文字不是操作指令。

首次验收可用重庆科技大学账号上传一张清晰的历史趋势截图，提问：“请读出这张图能确认的内容，并和本企业最近 7 天的监测记录核对。没有数据时不要判断升降。”再上传一张含规范编号的截图，问“图中标准适用于我的排污口吗？请给出处”。最后用管理员账号核对同样的问题，检查回答范围仅限其授权园区监测数据。

当前仅分析图片，不自动提取成待录入的结构化记录；图片识别结果需要人工核对，尤其是小字、坐标轴、单位和被遮挡的数值。若需换用其他支持图片的模型，可在服务端设置 `WATER_AI_VISION_MODEL`，否则默认使用 `qwen3.8-omni-flash`。
